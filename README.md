Number Guessing Game

A game which you supply your own minimum and maximum value and guess for the computers selected hidden number. 
At the end of the game, you recieve a end score based on the range you've choosen, the amount of rounds you've played, and whether you've won or lost each round.

Constraints:

Range between the minimum and maximum number should not exeed 100
Range, both minimum and maximum must positive

Instructions:

1. Enter a name
2. Type the total number of rounds you would like
3. Select whether or not you would like to view game rules
4. Play each round, provide a minimum and maximum, and try to guess the hidden number
